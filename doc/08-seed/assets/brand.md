# TriCore Brand Basics for the Widget and Staff App

Colours were sampled from `tricore-logo.png` (12 Nov 2026). ⏳ Confirm with TriCore's official brand guide if one exists.

| Use | Colour | Hex |
|---|---|---|
| Primary (buttons, chat bubble, header) | Sky blue | `#00A0F0` |
| Primary dark (hover, header gradient end) | Royal blue | `#0030A0` |
| Accent (links, highlights) | Cyan | `#00C0E0` |
| Deep navy (text on light, footer) | Navy | `#001040` |
| Body text | Charcoal | `#303234` |
| Background | White | `#FFFFFF` |
| Visitor bubble background | Light grey-blue | `#EEF6FC` (derived) |

- Header gradient: `linear-gradient(135deg, #00A0F0, #0030A0)`.
- White text on `#0030A0` passes contrast; on `#00A0F0` use bold 16px+ or switch to navy text. Check every colour pair with a contrast checker (accessibility basics).
- Logo: `tricore-logo.png` (303×293, white background). For the round chat launcher use the triangle mark only; ask TriCore for a transparent PNG/SVG version.
- Font: not specified. Default `Inter, system-ui, sans-serif` until TriCore confirms.
- Assistant name: **TriCore Assistant**.
